## 🧑‍💻 About me

I believe good ideas are born from curiosity and grow through collaboration. I work with data in the financial sector, right between analytics and engineering: I build the pipelines and also the metrics that run on top of them.

- 🔧 I build data extraction and transformation pipelines with **Python** and **SQL**
- 📊 I develop **Power BI** dashboards with star schema modeling and **DAX**
- ⚙️ I automate routines and reports with **GitHub Actions**, **Docker** and **n8n**
- 🖥️ I create internal applications with **Streamlit**
- 🎓 Graduated in Systems Analysis and Development from UniRitter
- 📚 Completed the Data Analysis with Python track of the Geração Caldeira 2024 program (Instituto Caldeira)
- 🌱 Currently deepening my knowledge in data engineering, AI and machine learning
- 📍 Rio Grande do Sul, Brazil
